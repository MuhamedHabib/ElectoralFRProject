## Overview

ElectoralFRProject is a Django web application that serves as the main website of a
fictional political party, **Jeunesse Démocrate** ("Democratic Youth"), with the slogan
*"Le changement, c'est maintenant!"* ("Change is now!"). It was built as an academic
project, with all visible content written in French.

The site presents the party's identity, electoral programme, team, and a simple blog.
It is organized into two Django apps:

- **`appportfolio`** — the public-facing pages (home, programme, team).
- **`appblog`** — a basic blog where posts can be authored and published through the
  Django admin and read by visitors.

The project runs on SQLite with a Bootstrap 4 front-end and is intended as a learning
exercise in building a content-driven Django site.

## Features

- **Home page** — party introduction, priorities (Education, Economy, Youth), and a
  carousel of supporter testimonials.
- **Programme page** (`/resume/`) — the party's electoral programme, grouped into social
  and economic themes, with detailed position statements.
- **Team page** (`/experience/`) — profiles of the party's members and their roles
  (President, Vice-President, Secretary General, etc.).
- **Blog** (`/blog/`):
  - List view of published posts with pagination (5 posts per page).
  - Individual post detail pages addressed by SEO-friendly slug.
  - A `posts` model with title, slug, author (linked to Django users), content, meta
    description, status (Draft / Publish / Delete), labels, and timestamps.
- **Django admin** — posts are registered in the admin for content management.
- **Static assets** — per-app CSS, images, and favicons; Bootstrap 4 and Font Awesome
  loaded via CDN.

## Getting Started

> All commands below run from inside the **`projectportfolio/`** directory, which
> contains the working `manage.py`.

1. **Clone the repository**

   ```bash
   git clone https://github.com/MuhamedHabib/ElectoralFRProject.git
   cd ElectoralFRProject/projectportfolio
   ```

2. **Create and activate a virtual environment**

   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS / Linux
   source venv/bin/activate
   ```

3. **Install Django**

   The repository does not ship a `requirements.txt`, so install Django directly
   (Django 3.1.x matches the settings this project was generated with):

   ```bash
   pip install "Django>=3.1,<3.2"
   ```

4. **Apply database migrations**

   ```bash
   python manage.py migrate
   ```

5. **Create an admin user** (to author blog posts)

   ```bash
   python manage.py createsuperuser
   ```

6. **Run the development server**

   ```bash
   python manage.py runserver
   ```

   Then open <http://127.0.0.1:8000/> for the site and
   <http://127.0.0.1:8000/admin/> for the admin.

## Notes

- **Academic project.** This is a learning exercise; the party, programme, and team are
  fictional. Content is in French.
- **Two `manage.py` files.** The functional entry point is `projectportfolio/manage.py`
  (it points to `projectportfolio.settings`). The `manage.py` at the repository root
  references a settings module that is not present, so run commands from the
  `projectportfolio/` directory.
- **Development configuration only.** `DEBUG = True` and the default SQLite database are
  set for local development and are not suitable for production. Before deploying, set
  `DEBUG = False`, configure `ALLOWED_HOSTS`, and move the secret key to an environment
  variable.
- **Project layout.** The internal project module is named `projectportfolio`; the
  repository is named for the French electoral ("électoral") theme of the academic
  assignment.
